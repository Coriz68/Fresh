GESTIONALE PREVENTIVI — VERSIONE 1.0.1

INSTALLER WINDOWS
- Il setup `Gestionale Preventivi 1.0.1 Setup.exe` installa l'app autonoma su Windows 10/11 a 64 bit; Python non è richiesto.
- Se Microsoft Edge WebView2 Evergreen Runtime manca, il setup lo installa automaticamente; serve una connessione Internet.
- Consulta `docs/INSTALLAZIONE_WINDOWS.md` per checksum, avvisi di sicurezza e istruzioni di installazione.

REQUISITI PER AVVIO DALLA SORGENTE
- Python 3 installato sul computer.
- Connessione internet solo al primo avvio, per installare pywebview nella cartella .venv.
- Su Windows è necessario il runtime WebView2; il setup per il cliente lo installa automaticamente quando manca.

AVVIO SU MAC
1. Fai doppio clic su Avvia_gestionale.command. Se macOS lo blocca, usa il menu contestuale > Apri.
2. Al primo avvio viene creata la cartella .venv e installata la dipendenza desktop; gli avvii successivi aprono direttamente la finestra.
3. Si apre una finestra desktop. Chiudi la finestra per terminare il programma.

AVVIO SU WINDOWS
1. Installa Python 3 e, se necessario, WebView2.
2. Fai doppio clic su Avvia_gestionale_windows.bat.
3. Al primo avvio vengono installati i componenti necessari in .venv; gli avvii successivi aprono direttamente la finestra.

PRIMO AVVIO E ARCHIVIAZIONE
1. Apri Azienda e PDF e scegli una cartella locale per il database. Il file si chiama preventivi.json.
2. Se la cartella scelta contiene già un database valido, il gestionale lo apre. Se è vuota e hai dati già aperti, scegli se copiarli o iniziare da zero.
3. Scegli due cartelle PDF distinte: una per i clienti e una per il fornitore.
4. Configura ragione sociale, contatti, logo, IVA e listino; salva le impostazioni.
5. Il database è JSON in chiaro sul disco scelto. Esporta regolarmente un backup e proteggi l’accesso al computer.

PREVENTIVI E PDF
1. Crea o seleziona un cliente, aggiungi i moduli e compila ciascun modulo originale.
2. “Genera PDF cliente completo” crea un documento con riepilogo, dati aziendali e cliente, prezzi, sconti, IVA, note e tutti i moduli. Ogni modulo riporta il nome del cliente e il numero del preventivo.
3. “Genera PDF fornitore · soli moduli” crea il PDF con le pagine originali dei moduli, senza riepilogo commerciale e senza prezzi; i moduli riportano nome cliente e numero preventivo.
4. Ogni PDF viene salvato nella cartella scelta per la relativa destinazione. Se un file con lo stesso nome esiste già, viene creato un nome con suffisso numerico.
5. La finestra di anteprima permette anche di scaricare una copia.

VERIFICA WINDOWS
Prima della consegna, prova installazione, avvio, generazione dei due PDF, cartelle locali, backup e disinstallazione su un computer Windows 10/11. Il setup non è firmato digitalmente e Windows potrebbe mostrare l'avviso per autore sconosciuto.
